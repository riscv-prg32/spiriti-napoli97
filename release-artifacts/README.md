# Release artwork

- `spiriti-napoli97-contact-sheet.png` and `screens/` are exact frames of `game.c`, rendered by the host harness as the ESP32-C6 palette shows them (`make screens`).
- `qemu/` holds frames and the boot log captured from the cartridge running in PRG32's QEMU firmware (`make capture`). The same run produces `preview.mp4` and `screenshot.png` at the top of the repository.

The Store bundle and both architecture variants are in `dist/`.
